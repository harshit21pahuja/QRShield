Abstract—QR codes have quickly become a part of everyday life—powering contactless payments, digital menus, transit passes, and two-factor login prompts. However, this convenience comes with a growing security risk known as quishing (QR code phishing). Because humans cannot decipher the pattern of a 2D barcode with the naked eye, attackers easily hide phishing links inside QR codes, bypassing traditional email filters and misleading mobile users. In this project, we built QRShield, an explainable multimodal system that evaluates QR codes locally before the user visits them. QRShield relies on a strict Zero-Contact policy: the QR code is decoded locally in memory using OpenCV without making any live network calls, browser requests, or DNS queries. We combine two complementary detection branches: a 29-feature static lexical Random Forest model analyzing URL structure and Shannon entropy, and a fine-tuned MobileNetV2 convolutional neural network examining the raw QR image matrix. The two branch outputs are combined using soft voting (55% URL / 45% Image) and calibrated using Isotonic Regression to provide trustworthy risk probabilities. Evaluated on a 70,000-sample partition of the CIC-Trap4Phish dataset split strictly by domain to prevent data leakage, QRShield achieves 98.77% accuracy, 99.67% ROC-AUC, and 99.27% F1-score. Crucially, multimodal fusion reduced false alarms by 86.2% compared to URL-only analysis (from 40.75% down to 5.61%), while running in just 5.91 ms on a standard CPU. We also integrate TreeSHAP feature attributions and Grad-CAM visual heatmaps so users can clearly see why a link was flagged.
Index Terms—Quishing Detection, Multimodal Deep Learning, Explainable AI (XAI), Zero-Contact Security, MobileNetV2, Probability Calibration.

I. INTRODUCTION

Scanning a QR code with a smartphone camera has become second nature for most people. We use them daily at restaurant tables, metro ticket gates, parking meters, and to log into desktop web applications. However, this simple physical-to-digital bridge has introduced a major security loophole known as quishing (QR code phishing).

When a user sees a regular link in an email or message, they can usually inspect the text, look at the domain name, or hover their mouse to see where it leads. With QR codes, that visual check is completely lost. A QR code is simply a grid of black and white squares with built-in error correction. To the human eye, a genuine QR code pointing to a trusted banking portal looks virtually identical to a malicious one pointing to a fake credential-harvesting page. Attackers take advantage of this physical air gap in several ways. In physical spaces, they paste printed sticker overlays on genuine public signage, such as municipal parking meters, exploiting people's natural trust in physical objects. In corporate environments, attackers place QR codes inside PDF invoices and image attachments, which cleanly bypass standard text-based email filters and security gateways.

Most existing solutions handle QR codes in one of two flawed ways:

1) Blind Execution: Standard camera apps simply decode the URL and ask the user to open it, relying on basic browser reputation lists (like Google Safe Browsing) after navigation has already started. This fails against newly registered phishing domains and zero-day lures.

2) Risky Dynamic Crawling: Many automated scanners test links by actively visiting them or opening headless browser sessions. While this helps trace HTTP redirects, it introduces serious security risks on a client device: it exposes the user to drive-by browser exploits, and it alerts attackers (via unique tracking IDs in the URL) that a real victim scanned the code.

3) Opaque Warnings: Existing security tools that do flag suspicious links typically show generic warning popups without explaining what was wrong, which causes alarm fatigue and leads users to ignore the warning.

To address these shortcomings, we built QRShield, an explainable multimodal detection system. Our core contributions in this project are:

• Zero-Contact Local Architecture: Decoded URLs are treated strictly as inert text in memory. We never perform HTTP requests, DNS lookups, or web crawling, ensuring zero risk of drive-by malware or attacker tracking.

• Leakage-Free Benchmark Dataset: We cleaned and canonicalized the benchmark CIC-Trap4Phish dataset (processing 2.15 million raw records down to 387,015 verified sample pairs). We strictly split our 70,000 working samples by registrable domain (eTLD+1) into train (50,000), validation (10,000), and test (10,000) splits so the model is tested on completely unseen domains rather than memorizing domain names.

• Multimodal Fusion: We combine a 29-feature static lexical Random Forest classifier with a lightweight MobileNetV2 CNN using a 55/45 weighted soft-voting strategy.

• Probability Calibration: We applied Isotonic Regression to fix the overconfidence typical of raw neural network outputs, reducing calibration error (Brier score) by 61.5% and finding an optimal decision threshold (τ = 0.5434).

• Dual Explainability: We integrated TreeSHAP to show users which lexical URL features drove the prediction, alongside Grad-CAM visual heatmaps highlighting which QR code regions the vision model focused on.

• Working Prototype: We built a full-stack working implementation featuring a FastAPI backend and a clean React 18 frontend that processes scans in 5.91 ms on CPU, verified by 10 automated unit and integration tests.

II. LITERATURE SURVEY

In recent years, researchers have explored phishing detection using lexical analysis, computer vision, and explainable AI: Al-Saeed et al. [1] evaluated tree-based machine learning models on static lexical URL features, achieving 94.2% accuracy. However, they ignored barcode imagery and suffered from domain leakage. Sandler et al. [2] introduced MobileNetV2 with inverted residuals for mobile edge computing, though barcode security was not examined. Vasant et al. [3] analyzed physical sticker overlays on 500 QR scans, confirming optical tampering cues, but lacked automated ML triage. Lundberg & Lee [4] developed TreeSHAP for tabular interpretability, and Selvaraju et al. [5] introduced Grad-CAM for CNN saliency, though neither addressed multimodal quishing. Gupta et al. [6] proposed a multimodal detector on PhishIntra (15,000 sites), but required live crawling (>2.5 s latency). Chataut et al. [7] formalized zero-trust mobile validation, while CIC [8] released the benchmark CIC-Trap4Phish dataset, which required thorough canonicalization to resolve label contradictions.

Synthesis & Research Gap: Existing research generally falls into two extremes: analyzing text links in isolation, or using heavy computer vision models that require live webpage crawling. Few works explore static multimodal fusion of both the QR image and its encoded URL, and even fewer calibrate their probabilities or explain their decisions. QRShield bridges this gap by offering a fast, zero-contact, multimodal pipeline with calibrated confidence and dual explainability.

III. PROPOSED METHODOLOGY

A. Zero-Contact Ingestion & Local Decoding

When an image tensor I is ingested, OpenCV's localized detector extracts the inert string S = DecodeMatrix(I). The string is stored strictly as an immutable text buffer in RAM. No external socket connections, DNS resolutions, or HTTP requests are initiated.

B. 29 Static Lexical Features (URL Branch)

We extract 29 numerical features x in R^29 across six categories: Lengths, Delimiters, Character Ratios, Query Attributes, Protocol Flags, and Shannon Information Entropies:

H(T) = -∑i=1k p(ci) log2 p(ci) (1)

where p(ci) is character frequency across string T. The lexical vector x is evaluated by a 300-tree Random Forest classifier:

Purl = (1 / M) ∑m=1M fm(x) (2)

C. Deep Visual Modeling (MobileNetV2 CNN Branch)

Raw QR images are rescaled to 224x224 RGB tensors and evaluated via MobileNetV2. Two-stage transfer learning was structured as follows: Stage A trained the linear head with AdamW (lr = 0.001) for 2 epochs; Stage B fine-tuned residual blocks 14–18 at lr = 0.0001 for 2 epochs.

Pimg = σ(zimg) = 1 / (1 + e-zimg) (3)

D. Multimodal Fusion & Isotonic Probability Calibration

Branch outputs are combined via prediction-level soft voting:

Praw = 0.55 × Purl + 0.45 × Pimg (4)

To eliminate overconfidence in raw model scores, non-parametric Isotonic Regression is applied using PAVA:

min ∑ (yi - g(Praw, i))2 s.t. g(pa) ≤ g(pb) ∀ pa ≤ pb (5)
Pcal = giso(Praw) (6)
ŷ = 1 if Pcal ≥ 0.5434 else 0 (7)

E. Dual Explainability Engine

TreeSHAP computes exact Shapley additive explanations phi_i:

IV. EXPERIMENTAL RESULTS

We evaluated our models on an NVIDIA Tesla T4 GPU (16 GB VRAM) for training, and benchmarked inference on an Intel Core i7 CPU (16 GB RAM) using Python 3.13, PyTorch 2.14, and Scikit-Learn.

A. Dataset Description

We used the CIC-Trap4Phish benchmark dataset from UNB. From the raw repository of 2.15 million records, our cleaning pipeline produced 387,015 clean sample pairs. For our controlled experiments, we created a 70,000-sample benchmark partitioned strictly by Registrable Domain (eTLD+1) into 50,000 train, 10,000 validation, and 10,000 test sets with zero domain overlap. Ethically, all URLs are treated strictly as inert strings without initiating live network requests.

V. CONCLUSION

In this project, we developed QRShield to tackle the emerging threat of QR code phishing. By combining 29 static lexical features with a deep MobileNetV2 image model under a strict Zero-Contact policy, the system prevents drive-by attacks while providing fast, reliable threat detection. On a domain-partitioned test set of 10,000 samples from CIC-Trap4Phish, QRShield achieved 98.77% accuracy and 99.27% F1-score, reducing false alarms by 86.2% over single-modality baselines. Isotonic calibration improved probability reliability by 61.5%, while TreeSHAP and Grad-CAM offer clear, actionable explanations in just 5.91 ms on CPU. In the future, we plan to quantize the model for on-device mobile execution on Android and iOS (via ONNX Runtime), integrate an offline Bloom filter for known threats, and test robustness against printed barcode damage.
